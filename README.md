# affiliate-office-media

Affiliate Office(쿠팡파트너스 × Threads) 게시물용 이미지 저장소입니다.

이 저장소는 **공개**입니다. Threads API가 이미지를 게시하려면 공개 URL이 필요하고
(Meta가 해당 주소에서 이미지를 가져갑니다), 여기 올린 파일은
`https://raw.githubusercontent.com/<사용자>/affiliate-office-media/main/<경로>`
로 접근할 수 있습니다.

- 게시에 쓰는 이미지만 올립니다. 코드·자격 증명·회사 기록은 비공개 저장소에 있습니다.
- 경로 규칙: `posts/<캠페인>/<게시ID>-<순번>.png`
- 한 번 올린 이미지는 게시물이 살아 있는 동안 지우지 않습니다.
